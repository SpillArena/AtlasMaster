AtlasMaster: geography with maps and quizzes

AtlasMaster tests geographical knowledge, from Norway to the rest of the world. Topics include countries, capitals, cities, rivers and mountain peaks. Maps put each answer in a spatial context rather than presenting names alone.

How to play

Choose a region and question type. Read each prompt before answering on the map or in the quiz. Use the feedback to identify the correct place, then return to the topics you find difficult.
